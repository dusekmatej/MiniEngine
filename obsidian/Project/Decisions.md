# Decisions

Decision notes record durable choices, not temporary implementation details or AI suggestions. Do not create a decision note by inferring an intent that the repository does not state.

## Recorded

- [[Project/Decisions/Entity handles carry generations]] — current entity identity design.
- [[Project/Decisions/Systems are discovered automatically]] — documented system registration approach.
- [[Project/Decisions/Graphics go through engine contracts]] — current boundary direction and its limits.

## How to Add One

Use [[Templates/Decision]]. State whether the note records an adopted decision, an observed current pattern, or a proposed decision awaiting confirmation. Link the relevant source files and do not let a planned refactor overwrite a current implementation fact.
